# Smartory-App Backend

1. Instalar las dependencias ```yarn o yarn install```

2. Clonar el archivo .env.template y renombrar la copia a .env

3. Configurar variables de entorno

4. Correr el proyecto con
```
yarn start:dev
```

## Stack

* NestJS
* Postgres
